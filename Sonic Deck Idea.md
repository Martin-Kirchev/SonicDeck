Sonic Deck is a plugin for MiraBox, witch is a program for Stream Deck add-ons.

Sonic Deck's main purpose is to control the Spotify app on your machine with a set of buttons, that can be accessed directly from the Stream Deck as a shortcut.



The plugin should have these shortcuts:

* open Spotify
* play/pause song in Spotify
* change song to previous/next in Spotify
* change volume up/down/mute in Spotify
* show information about current song (song name, artist, art)
* show current song time (song progress)
* turn on/off shuffle/repeat
* start a chosen album
* change song device



The end product should: 

* include all listed shortcuts, which have an icon (dynamic if relevant for the shortcut)
* be able to be updated and modified (for updates and bug fixes)
* be downloadable for anyone from the MiraCraft plugin store (if possible without paying money)
