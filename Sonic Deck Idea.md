Sonic Deck is a plugin for MiraBox Stream Dock, a program for customizing Stream Dock keys. The currently working prototype is a loader/key-event test; the Spotify controls described below are the product vision and are not implemented yet.

Sonic Deck's main purpose is to control the Spotify app on your machine with a set of buttons, that can be accessed directly from the Stream Deck as a shortcut.

The project will have two types of features a must have features and a "nice to have" features.

The longer-term product vision includes these features:

* open Spotify
* play/pause song in Spotify
* change song to previous/next in Spotify
* show information about current song (song name, artist)


The plugin might have these features, if there is enough time:

* change volume up/down/mute in Spotify, subject to Spotify API support or separate Windows audio-control work
* show information about current song (art)
* show current song time (song progress)
* turn on/off shuffle/repeat
* start a chosen album
* change song device


The end product should:

* include at least all of the listed must have shortcuts
* include a design for all of the available shortcut (dynamic if relevant for the shortcut)
* be able to be updated and modified (for updates and bug fixes)
* be downloadable for anyone from the MiraBox plugin store (if access policies and store requirements permit)

The January 2027 beta scope is narrower than this vision; see [Sonic Deck Product Specification](Sonic%20Deck%20Product%20Specification.md) for its committed actions, deferred features, and validated prototype SDK/package details.
